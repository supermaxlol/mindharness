# World Canon — The Ledger Principle v2

## The one loop
A system writes a trace, tags what matters, builds structure, replays offline,
checks against a record before the next act. Pattern persists through turnover
only while maintenance holds inside physical bounds.

## The five organs (always all five)
1. Boundary — decides inside vs outside.
2. Two-speed memory — fast trace + slow store + consolidation step.
3. Salience gate — tags what to keep.
4. Damping — prevents runaway.
5. Observer — slower loop with veto power.

## The grades (evidential status, never skipped)
- measured: our pull or held primary, file exists.
- convergent: independent labs, same shape.
- analogical: same type, different substrate; design guidance only.
- open: unresolved, named with falsifier.

## The protagonist
The Ledger itself: born as tally-clay, becomes law, library, balance sheet,
treaty, weight file, provenance receipt. Want: persist pattern. Need: a
witness it cannot rewrite. Lie it tells itself: the narrator is the check.

## Hard rules
- Story first, receipts in back (appendix).
- One mechanism per chapter, first paragraph.
- Pop anchor + metaphor boundary for every dense concept.
- No em dashes. No new LaTeX packages. Numbers and grades never promoted.
