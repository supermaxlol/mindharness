# Style — voice and pacing rules for bookv2

## Voice
- Ghazalian mechanics, bestseller pacing. Trapdoor elimination +
 taxonomy + ego-as-antagonist ("You might tell yourself...") with litmus
 tests. Scientist-and-poet fusion; clinical diagnostician for vices.
- Want vs need for every concept-character. Lie named early, shattered late.
- Subtext over statement where the scene allows; moral argument resolved
 at each climax, not just events.

## Translation ladder (every dense concept)
1. Pop anchor the reader already owns. Prefer the ten allegories
 (\S\ref{sec:appendix-allegories}): Cave for prediction-vs-world, Butterfly
 for stitched now, Prince/Cobbler for ledger-not-stuff, Swampman for
 history-less copy, Chinese Room for watcher-less theatre, Mary's Room
 for gain-vs-fact, Experience Machine for brake-less pleasure, Heap for
 thresholds, Sisyphus for re-injection discipline, Flatland for slices
 vs sphere. Use any other familiar context wherever people already own
 it: Memento for drift without re-injection, Google Docs auto-save for
 the ledger harness, muddy pool for stillness-vs-stirring, bus schedule
 vs ride-share for intrinsic-time execution. Whatever people know wins.
2. Structural link: why the topic behaves like the anchor.
3. Specific finding: the technical takeaway with its grade.
4. Metaphor boundary: state where the anchor breaks to show authority.

## Failed walk
Never present only the final rule. Give the 2-sentence failure story
(steering that sensitizes itself into a ditch; model amplifying into
nonsense) so the fix carries weight.

## Prose guards
- 30% thematic focus: the loop, always the loop.
- High-agency verbs; contractions where spoken; concrete nouns.
- Physical friction for numbers (basement water for S_t, pavement vs mud
 for +75%, haircut-points for P1/P0).
- Trim on-ramps: cut first two paragraphs of every draft chapter, start
 late, end on micro-cliffhanger bridges.
- Grades stay single italic words with file pointers. No audit prose in body.
- No em dashes (hyphen-minus only). No new LaTeX packages.
- Numbers/grades never promoted. New threads enter as analogical/open.

## Verification per batch
- One chapter file touched at a time. Canon updated if a new term lands.
- lsp-style check: rebuild with 2x pdflatex, 0 errors, 0 undefined.
- Auditor pass: grep new terms across chapters for definition drift.
