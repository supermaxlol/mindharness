# V3 source re-audit: where the first edit became too cautious

**September 26 placement update:** The agency material discussed below is now in Chapters 14–15, after the machine sequence, consciousness hinge, and synthesis. Its evidence decisions are unchanged; `BOOK3_CANONICAL_SPINE.md` controls current order.

This pass searched the V3 chapters, plan, comparison, translation map, source walk, and evidence database for claims I had weakened, removed, or sent to an appendix. I compared each with the archive and the cited primary work, then revised the actual prose. A trade book can advance a strong synthesis from converging evidence. The source trail still has to say what was measured so that the synthesis is earned rather than merely repeated.

## Boundaries retained after checking

- **Animal culture:** [Bumblebee](https://www.nature.com/articles/s41586-024-07126-4) and [pigeon](https://www.nature.com/articles/ncomms15049) transmission findings rule out a literal “all animal knowledge resets to zero” opening. Chapter 1 keeps the stronger human difference: explicit, revisable, durable symbolic archives.
- **The bank's $100.4 billion:** The [2010 Form 10-K](https://www.sec.gov/Archives/edgar/data/70858/000095012311018743/g25571e10vk.htm) describes assets newly consolidated onto the balance sheet. The figure is powerful precisely because the visibility rule moved; it is not a measured realized loss.
- **Legal recovery:** `A = 0 ⇒ K = 0` works when `A` counts every legally reachable recovery source for that claim. An offshore parent does not by itself establish that `A` is zero. [ICSID](https://icsid.worldbank.org/procedures/arbitration/convention/recognition-enforcement) distinguishes an award's recognition from execution against assets.
- **Local negative controls:** The S126 checker read an empty ledger, while the navigation experiment's sham watcher and coordinate-keyed transfer also exposed failures. These are valuable failed walks. They should remain in the book beside the successful relational-memory result, with the actual wiring and baselines visible.

The practical edit rule going forward: verify an unfamiliar claim before softening it. When the source supports a striking number, keep the number and name its measured unit. When several methods converge on a larger mechanism, state the mechanism as the book's inference and show the rival explanations it defeats.
